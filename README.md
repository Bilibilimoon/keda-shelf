# 可达书柜（mangagate）

给飞牛 fnOS 用的小型书柜服务端。它把 NAS 上的漫画目录变成书架，让 iOS 上的
**可达阅读器**（以及任何支持 OPDS 1.2 的客户端）直接连接，省去配置
SMB 共享的麻烦。

> 维护者 / 后续开发者请同时阅读 [DEVELOPMENT.md](DEVELOPMENT.md)：架构、关键决策、
> fnOS 平台坑、测试方法和发版流程都在那里。

- 一个进程、一个端口，提供 **OPDS 1.2** 书架；多个授权目录自动合并，
  每个目录一个书库入口，另有「最近添加」和分页
- 支持 CBZ / ZIP / CBR / RAR / EPUB / PDF 压缩包，也支持「一个文件夹里放图片」的漫画
- 自动从压缩包或文件夹里提取封面；epub / cbz 的内嵌元数据（作者、简介、
  标签、封面）自动读取
- 扫描时报告坏压缩包和读不了的目录，导入大库时不怕悄悄缺书
- 下载接口支持 HTTP Range，可达阅读器可以流式阅读大文件
- 多账号：所有账号都是只读用户，管理操作只允许飞牛 NAS 管理员
- 可以给每个账号按目录分配可见范围，家人各看各的
- 管理页可刮削补全作品信息：内置「批量尝试」（精确匹配自动应用，其余
  生成待确认建议），支持 AniList 与 Bangumi 双源
- 扫描结果缓存（重启秒开）、配置导出与导入
- 安装包自带 arm64 与 amd64 两个二进制，x86 和 ARM 的飞牛都能装
- 可选 HTTPS：同一端口同时接受 HTTP 与 HTTPS，证书路径在应用设置里填写

## 安装

1. 把 `mangagate.fpk` 拷到飞牛上，打开「应用中心 → 手动安装」，选择该文件。
2. 安装向导里填三项：管理员账号、管理员密码、服务端口（默认 **5080**）。
3. 安装完成后，进入「应用设置 → 授权目录」，选择漫画所在的共享文件夹（可以选多个，
   每个目录在书架里是一个独立书库）。保存设置后服务会自动重启并读取新的授权目录。
4. 打开飞牛桌面上的「可达书柜」图标，确认管理页里已经扫描出系列和书籍。

> 如果没有手动安装入口，需要在应用中心设置里允许安装第三方应用。

## 在可达阅读器里连接

**OPDS**

- 地址：`http://<NAS的局域网IP>:5080/opds/v1.2/catalog`
- 也可以只填 `http://<NAS的局域网IP>:5080`，由 App 自行探测
- 在可达阅读器里选择「OPDS 服务器」或「Komga / Calibre」类入口

管理页顶部会直接显示这个地址，点「复制」即可。

> 统一网关地址（`/app/mangagate`）只用于飞牛桌面里的管理页。App 走的是 Basic Auth，
> 没有 NAS 登录会话，无法穿过统一网关的鉴权，所以 App 必须用 `IP:端口` 地址。

### 公网访问

局域网以外要连 OPDS，需要用**你自己的域名**（或公网 IP）解析到这台 NAS，并在
路由器/防火墙放行服务端口，然后填 `http://你的域名:5080/opds/v1.2/catalog`。

飞牛自带的 `*.fnos.net` 域名走的是 fnConnect 中继，只转发飞牛自己的门户端口，
**不能用来访问第三方应用的 5080 端口**，`https://xxx.fnos.net:5080` 不会连通。

需要 HTTPS 时，在「应用设置」里填写 TLS 证书链和私钥的绝对路径（例如阿里云免费
证书或 acme.sh 签发的 `fullchain.pem` / `privkey.pem`），保存后服务会在**同一端口**
同时接受 HTTP 和 HTTPS。局域网原有的 `http://` 地址不受影响，公网改用
`https://你的域名:5080/opds/v1.2/catalog`。证书域名必须和访问的域名一致。

## 目录怎么组织

服务端会自动识别，不需要改名或建库：

```
漫画/
├── 星海旅人/            ← 一个文件夹 = 一个系列
│   ├── 第1卷.cbz
│   └── 第2卷.cbz
├── 日常小品/
│   ├── 第1话.zip
│   └── 第2话.zip
├── 图片样式/
│   └── 散图漫画/        ← 文件夹里直接是图片 = 一本
│       ├── 01.jpg
│       └── 02.jpg
└── 单本/
    └── 独立的一本.cbz
```

- 一个目录里只有图片 → 当作一本书；有子目录 → 递归成系列。
- `@eaDir`、`#recycle`、`.DS_Store`、隐藏文件会被跳过。
- 符号链接不会被跟随，所有访问都限制在授权目录内。

## 管理页

桌面入口打开后可以：

- 查看系列 / 书籍 / 页数 / 占用空间，点「重新扫描」刷新，扫描时显示进度，
  结束弹出结果；扫描异常（坏压缩包、读不了的目录）会列出来
- 在已授权的目录中切换漫画库根目录
- 添加、删除用户，重置密码
- 给每个用户按目录分配可见范围：权限弹层是目录树，勾选任意层级即可；
  默认全部可见，限制后只看勾选目录及其子内容（含以后新增的）
- 「系列信息」：为系列或单本书匹配 Bangumi 条目，补全作者、简介、标签和
  官方封面；搜索词自动去掉卷号和汉化组标记，刮削结果只存本机
- 查看最近 200 行运行日志，导出配置备份，或从备份文件导入（恢复用户、
  权限和刮削匹配）
- 复制 OPDS 连接地址

新增用户一律是标准用户，只能阅读。切换目录、重新扫描、增删用户、分配权限
这些管理操作**只允许飞牛 NAS 管理员**从桌面入口执行；普通用户即使直接访问
端口，也只能看到状态。

## 分发

把 `pkg/mangagate/mangagate.fpk` 发给别人即可，安装流程相同。包内同时包含：

- `mangagate-arm64`（飞牛 ARM 设备）
- `mangagate-amd64`（飞牛 x86 设备）

`cmd/main` 会在启动时按 `uname -m` 选择。两个二进制都是静态链接，不依赖
Node、Python 或 Docker。

卸载应用不会主动删除你的漫画文件。配置和账号保存在
`/vol1/@appconf/mangagate/`，运行数据和封面缓存在 `/vol1/@appdata/mangagate/`。

## 开发与构建

```bash
git clone git@github.com:Bilibilimoon/keda-shelf.git
cd keda-shelf
./build.sh
```

脚本会把 Go 工具链下载到 `tools/`（不安装到系统），用 `tools/icon.png`
生成各尺寸图标（不存在则绘制默认图形），编译两个架构，再用 `fnpack` 打包。
依赖：`curl`、`tar`、`fnpack`。

测试：

```bash
cd src && ../tools/go/bin/go test .   # 单元测试（解析/扫描/权限/分页等纯逻辑）
python3 tools/smoke_test.py --help    # HTTP 冒烟测试（权限/刮削可走本地 mock）
```

本机验证：

```bash
sudo appcenter-cli install-local -d pkg/mangagate -e /tmp/mg.env
```

`/tmp/mg.env`：

```
admin_user=admin
admin_pass=你的密码
port=5080
```

架构决策、fnOS 平台细节、测试方法与发版流程见 [DEVELOPMENT.md](DEVELOPMENT.md)。

测试样本可以用：

```bash
./tools/go/bin/go run tools/gen_sample.go --out testdata/library
```

## 限制与注意事项

- **只读**：OPDS 只提供下载，服务端不写漫画文件。
- **HTTP / HTTPS**：默认明文 HTTP，适合局域网；公网建议配置证书后使用 HTTPS。
  不要直接把明文 HTTP 暴露到公网。飞牛的 fnConnect 域名不能用于第三方应用端口。
- **RAR/CBR 封面**：服务端不解压 RAR，封面用占位图，不影响 App 阅读。
- **大库首次扫描**：启动时会遍历目录并统计压缩包页数，几万本会慢一些；扫描结果
  缓存在运行数据目录，之后重启立即可用，重新扫描时未变化的压缩包不再重新数页数。
- **用户可见范围**：权限按目录路径绑定；目录改名或换根目录后路径变化，
  需要重新分配（保存时会自动清掉失效路径）。漫画库最顶层的散图不属于任何
  子目录，受限用户看不到它们。
- **刮削**：内嵌元数据（epub 的 OPF、cbz 的 ComicInfo.xml）在扫描时自动读取；
  在线匹配使用 Bangumi（`api.bgm.tv`），需要 NAS 能访问外网。匹配信息保存在
  运行数据目录（`series-meta.json`），不会改动漫画文件；目录改名后系列匹配
  失效，重新匹配即可。刮削需要 NAS 管理员在管理页手动确认，不做全自动。
- **EPUB**：按 zip 直接下发给阅读器，页数按内含图片数估算；带 OPF 元数据时
  显示作者/简介，封面用声明封面。
- **授权目录变更**：保存应用设置后会自动重启；如果平台没有触发自动重启，手动
  停止再启动一次即可。
- 管理页登录失败有频率限制（每分钟最多 3 次，超过后需等一分钟再试）。

## 技术栈

Go 1.23，标准库 + `golang.org/x/crypto/bcrypt`、`golang.org/x/image`。
全部静态编译，运行身份为专用 `mangagate` 用户。
